# HR Assist
 
A local, tool-using HR recruitment assistant built with [LangChain](https://python.langchain.com/) and [Ollama](https://ollama.com/). It answers company policy questions using retrieval-augmented generation (RAG) over your HR documents, extracts structured candidate details from resumes, checks candidate eligibility, and generates interview questions — all running on a local LLM, no external API keys required.
 
## Features
 
- **Policy Q&A (RAG)** — Answers questions about leave, notice period, working hours, work-from-home, and dress code by retrieving relevant chunks from your HR documents via a FAISS vector store, then grounding the LLM's answer in that context.
- **Resume parsing** — Paste resume text prefixed with `resume:` and get back structured candidate details (name, experience, skills) using a Pydantic schema.
- **Eligibility checking** — Checks a candidate's skills against required skills (Python, SQL, Git) via a dedicated tool.
- **Experience calculator** — Computes years of experience from a candidate's start year.
- **Interview question generation** — Generates interview questions tailored to a given skill set.
- **Tool-calling agent** — General queries are routed through a LangChain agent that decides which tool(s) to call.

## Prerequisites
 
- Python 3.9+
- [Ollama](https://ollama.com/) installed and running locally
- The following Ollama models pulled:
```bash
  ollama pull qwen2.5:3b
  ollama pull nomic-embed-text
```
 
## Installation
 
```bash
git clone <your-repo-url>
cd "HR Assist"
pip install langchain langchain-core langchain-community langchain-ollama langchain-text-splitters pydantic faiss-cpu
```
 
## Usage
 
### 1. Build the vector store
 
Run this once (and again any time the source `.txt` documents change) to index your HR documents:
 
```bash
python vector_db.py
```
 
This reads `EmployeeHandbook.txt`, `LeavePolicy.txt`, and `PythonDeveloperJD.txt`, splits them into chunks, embeds them with `nomic-embed-text`, and saves the index to `hr_vector_db/`.
 
### 2. Run the assistant
 
Make sure Ollama is running, then start the CLI:
 
```bash
python hr_agent.py
```
 
Example interactions:
 
```
You : What is the notice period?
Assistant: The standard notice period is 60 days.
 
You : resume: Arjun, 3 years experience, skills Python SQL Git Django
Candidate Details
name='Arjun' experience=3 skills=['Python', 'SQL', 'Git', 'Django']
 
You : exit
```
 
Type `exit` at any time to quit.
 
## How it works
 
- **Policy questions** are detected via keyword matching (leave, notice, handbook, dress code, etc.) and answered by retrieving the top matching chunks from the FAISS index, then asking the LLM to answer strictly from that retrieved context.
- **Resume input** (`resume: <text>`) is parsed directly into a structured `Candidate` object using `llm.with_structured_output()`.
- **Everything else** is routed to a LangChain tool-calling agent, which decides whether to use the calculator, eligibility checker, or interview question generator tool.
## Troubleshooting
 
**`Could not load FAISS index 'hr_vector_db': '__fields_set__'`**
This means the index was built with a different `pydantic`/`langchain` version than the one currently installed. Delete the `hr_vector_db` folder and rebuild it locally with `python vector_db.py` so the pickle matches your environment.
 
**`Error in StdOutCallbackHandler.on_chain_start callback: AttributeError("'NoneType' object has no attribute 'get'")`**
A known LangChain issue triggered by `AgentExecutor(verbose=True)`. It's set to `verbose=False` in this repo to avoid it; the assistant still works correctly even though you won't see step-by-step tool-call logs in the console.
